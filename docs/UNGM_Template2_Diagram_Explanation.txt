No proprietary product components; no blockchain; core scoring is deterministic TypeScript agents (not GenAI/LLM).

CLIENT-SIDE (Browser) — COMPLETE
• Next.js 15 App Router + React 19 + TypeScript + Tailwind CSS 4 + lucide-react: presentation UI.
• Pages /dashboard, /india, /play, /pitch: country/city/India analysis, age-banded kids play, stakeholder narrative.
• Selectors + ReportView + IndiaImpactPanel + KidsPlayHub: render SynthesisReport and missions.
• localStorage play progress only: XP/badges/streaks; no child accounts or client DB.
• Tooling: ESLint, next build, GitHub Actions CI.

SERVER-SIDE (Node.js) — COMPLETE
• Next.js Route Handlers: POST/GET /api/analyze; GET /api/countries; GET /api/india/regions.
• Zod validation of analyze requests.
• orchestrator.ts meta-layer: sequences agents, India gate, agent status, SynthesisReport JSON contract.
• Persistence: no SQL/NoSQL database in demo — stateless analyze + in-repo TypeScript registries.

DOMAIN AGENTS + REGISTRIES — COMPLETE (expandable)
• Global agents: Climate, Health, Nutrition, Disease, Natural Medicine, Synthesis (age bands 5–8 / 9–12 / 13–17).
• India agents (when countryCode=IN): Regional Context; Child Health Impact / CHIS (CHVI, CRBS, WDPI, VBDP, CNSI).
• Registries: countries.ts (~159 countries / ~482 Tier 1–3 cities); india-regions.ts (77); sources.ts (~50); gamification.ts (missions/badges).
• Linkage: UI → HTTPS JSON API → Orchestrator → Agents → SynthesisReport → UI (ReportView / Play).
